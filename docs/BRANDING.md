# Opoint — Official Brand Usage

The permanent Opoint artwork is supplied in the owner's `Otya_Complete_Ecosystem_Logos_v2.zip`, folder `04_Retail_MoMo_Logo_Opoint/`.

## Correct placement

Use the exact Opoint artwork for the unified retail and mobile-money product, including the retail/mobile-money portal, POS and checkout, merchant/agent onboarding, receipts, app launcher and the `opoint-retail-momo` Google Cloud OAuth project.

Use:
- `Opoint_Retail_MoMo_Logo_Transparent.webp` or the exact transparent PNG for interface placements.
- `Opoint_Retail_MoMo_Logo_App_Icon_1024x1024.png` for app/icon placements.
- `Opoint_Full_Lockup_With_Text.png` where the complete lockup is required.
- The supplied white-background, monochrome, SVG and print files for their intended contexts.

Do not redraw, recolour, crop or recreate the logo. Keep all original proportions and transparency. Do not use the Otya parent logo or O AI/Omy marks in place of Opoint.

## Parent relationship

Opoint is a product within the Otya umbrella brand. Use the Otya parent logo only when the surface is explicitly representing the parent company or whole ecosystem.

## Rollout status

This document establishes the correct logo source and placement rules. App and website changes are not considered complete until the exact new files are present in the assets, the production build succeeds, and the deployed customer/staff surfaces have been visually checked.
